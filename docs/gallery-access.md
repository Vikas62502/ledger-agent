# Bajaj image gallery access

Agents normally get **RC only** upload options (RC front + RC back).

Full gallery (vehicle front/side + tag affix + RC) is granted when
`Users.galleryUploadEnabled = true` for that agent.

Ops can toggle this from Agent Approval → agent details.
If an agent complains they cannot pick vehicle photos from gallery,
check the Gallery column: `RC only` vs `Full`.
