# Offer and tag-cost refund basics

- **Offer credit** appears as a wallet reason like `Offer Applied_<title>`.
- **Tag cost refund** appears as `{VRN}_Refund_tag_cost`.
- **Issuance debit** appears as `Tag Issuance_{VRN}`.

If offer was not paid, common causes:
- vehicle class not eligible
- no active agent offer amount configured
- app-install offer flags did not match registration

Always confirm with ledger tools before telling support "not paid".
